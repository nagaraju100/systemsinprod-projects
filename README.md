# Systems in Prod — projects

Code and templates that go with the use cases on [systemsinprod.com](https://systemsinprod.com).
Real data & AI use cases, built for production.

## How this repo is organised

One folder per use case, named after its page on the site:

```
<use-case-slug>/
  README.md     what it does, how to run it, what to change
  ...           SQL, scripts, configs
```

Projects are added here as each use case is published on the site.

## Using a project

```bash
git clone https://github.com/nagaraju100/systemsinprod-projects.git
cd systemsinprod-projects/<use-case-slug>
```

Read that folder's README first. Run things on a workspace you are allowed to use, and review every query and setting before applying it to production.
